# N300 VPN 0.6.3

## Главное

- исправлена нестабильность прозрачного режима на RTL8197D;
- максимум одновременных клиентов снижен до 4;
- Reality/TLS handshakes запускаются с паузой, чтобы не перегружать 64 МБ RAM;
- перенаправляются только TCP 80/443;
- добавлена проверка YouTube и автоматический откат при неудаче;
- все рабочие данные рассчитаны на USB `/mnt/usb/n300vpn`.

## Проверка на целевом роутере

VLESS/Reality: успешно. YouTube: HTTP 200, страница и видеопоток получены. После отключения VPN прямой интернет восстановлен. Автозапуск VPN в релизе выключен по умолчанию.
