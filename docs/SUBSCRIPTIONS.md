# Подписки и зеркала

## Базовая подписка

Всегда используется VLESS-подборка проекта `igareck/vpn-configs-for-russia`.
В проекте нет встроенной пользовательской ссылки. Владелец может добавить из
панели ссылку Crunch того же формата, который используется Happ/V2RayTun.
Ссылка хранится только в `/mnt/usb/n300vpn/private/subscription.url` с правами
`0600` и никогда не возвращается браузеру.

## Каскад загрузки

Источники проверяются по одному с коротким тайм-аутом:

1. GitHub Raw;
2. GitLab;
3. Codeberg;
4. Gitea;
5. Bitbucket;
6. обычная страница загрузки GitHub.

Смена зеркала не меняет выбранный узел. После первого успешного ответа другие
зеркала в этом цикле не запрашиваются.

## Безопасное обновление

- ручное обновление доступно из панели;
- лимит ответа: 4 МиБ, тайм-аут соединения 5 секунд, общий тайм-аут 25 секунд;
- только HTTPS, не более двух redirect;
- пользовательская Crunch-ссылка разрешена только на точном HTTPS-хосте и
  читается ядром из файла, поэтому токен не виден в списке процессов;
- загрузка идёт во временный файл; затем выполняются разбор, дедупликация,
  проверка совместимости и последовательная endpoint-проверка;
- рабочие и `last-good` копии заменяются атомарно;
- если все зеркала недоступны или список пуст/повреждён, активная конфигурация
  не меняется.

## Ограничение слабого роутера

Репозиторий и пользовательская подписка могут содержать разные протоколы.
Сейчас в рабочий список попадают только конфигурации VLESS, совместимые с
проверенным Lexra-ядром. Адреса проверяются по одному. Глубокая проверка
YouTube берёт максимум 20 быстрых узлов выбранного источника и сохраняет все
успешные результаты, отсортированные в панели по времени загрузки.
