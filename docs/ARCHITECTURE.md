# Архитектура N300 VPN Manager

## Компоненты на USB

```text
/mnt/usb/n300vpn/
  bin/          Lexra-ядро, контроллер, парсеры и обновление
  nodes/        атомарно созданные конфигурации совместимых узлов
  state/        выбранные узлы, прогресс и результаты YouTube-тестов
  cache/        рабочие и last-good копии подписок
  private/      пользовательская ссылка с правами 0600
  certs/        корневые сертификаты для современного HTTPS
  www/          CGI-панель и статический JavaScript
```

## Состояния

`DIRECT` → `UPDATING`/`TESTING` → `CONNECTING` → `VPN`.

Любая ошибка до полного теста возвращает `DIRECT`. Правила переключаются
только после запуска ядра, проверки локального порта и контрольного HTTPS-
запроса через туннель. Адреса LAN, интерфейс управления и адрес VPN-сервера
всегда исключаются из проксирования до установки основной цепочки.

## Панель `http://192.168.2.1:8080/cgi-bin/n300vpn`

- статус VPN-процесса, маршрутов, фоновых проверок и подключений LAN/Wi-Fi;
- добавление, замена и удаление пользовательской подписки без показа её URL;
- отдельные разделы пользовательской подписки и репозитория;
- цветные метки источника и задержки;
- последовательная проверка YouTube и отдельный список всех успешных узлов;
- выбор устройств LAN1–LAN4 и Wi-Fi, которым разрешено использовать VPN.

UI состоит из Lua CGI и одного статического JavaScript-файла без фреймворков,
шрифтов и внешних CDN. CGI передаёт shell-контроллеру только проверенные ID и
короткие действия. Секретная ссылка записывается напрямую в фиксированный файл
на USB и не попадает в аргументы процессов.

## Бюджеты ресурсов

- один VPN-движок одновременно;
- разбор: максимум 256 совместимых узлов, жёсткий предел 512;
- быстрые endpoint-проверки: все кандидаты, строго по одному;
- глубокая проверка YouTube: до 20 кандидатов, строго по одному;
- одновременно допускается только один VPN-процесс или одна фоновая проверка;
- любое включение маршрутов выполняется только после реальной проверки узла.

## Движки

1. `n300vless` — рабочее нативное Lexra-ядро для VLESS TCP/WS/gRPC,
   TLS/Reality и Vision.
2. Xray 26.2.6 soft-float — отвергнут фактическим `SIGILL` на RTL8197D/Lexra.
3. Hysteria, XHTTP, VMess и Trojan не передаются рабочему ядру, пока их
   реализация не пройдёт отдельную проверку на целевом роутере.
